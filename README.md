# PRISMA カードコレクション

カードパックを何度でも無料で開封し、全395種類（2パック）のカード収集を目指すブラウザゲームです。
対戦・育成・課金要素はなく、パック開封とコレクションだけに特化しています。

- スマートフォン向け（PCブラウザでも動作）
- ビルド不要。HTML / JavaScript / CSS は `index.html` 1ファイルにまとまっています
- セーブデータはブラウザ内（localStorage）に保存

## 遊び方

1. タイトル画面で「ゲームスタート」
2. ホーム画面で開けたいパックを左右スワイプ（または矢印）で選び、タップすると10連開封
3. カードはタップで1枚ずつめくる（右上の SKIP で結果まで飛ばせます）
4. 「図鑑」で集めたカードを確認。上部でパックを切り替え、カードをタップすると詳細と共有画像

## 公開方法（GitHub Pages）

1. このフォルダの中身をリポジトリのルートに置いて push
2. リポジトリの Settings → Pages → Build and deployment で
   Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

## ローカルで動かす

`cards.json` を読み込むため、ファイルを直接ダブルクリックせず、簡易サーバーで開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## カード構成と排出率

排出率はどのパックも共通です。開封したパックのカードだけが出ます。

| レアリティ | 排出率 | BOOSTER 種類数 | 1種あたり | SWEETS 種類数 | 1種あたり |
|---|---:|---:|---:|---:|---:|
| N | 70% | 100 | 0.70% | 35 | 2.0% |
| R | 20% | 80 | 0.25% | 30 | 0.667% |
| SR | 8% | 60 | 0.133% | 20 | 0.40% |
| SSR | 1.97% | 40 | 0.0493% | 10 | 0.197% |
| UR | 0.03% | 15 | 0.002% | 5 | 0.006% |

- 1枚ごとに独立抽選（`crypto.getRandomValues` を使用）
- 確率固定・確率アップなし・重複あり
- 天井：同じパックで1000枚（10連100回）引くごとに「UR確定ガチャ」を1回引ける。
  確定ガチャは10枚目がそのパックのURから均等に確定、ほかの9枚は通常の確率。確定ガチャの10枚は天井に数えない
- 同じレアリティ内は均等
- 各パックで大量試行し、各レアリティの実測値が理論値と一致することを確認済み

## カードマスター（cards.json）

```json
{
  "id": "N001",
  "no": 1,
  "pack": "PRISMA BOOSTER PACK",
  "name": "いわのユニコーン",
  "rarity": "N",
  "element": "岩",
  "motif": "ユニコーン",
  "theme": "岩属性 × ユニコーン",
  "file": "illust/N001.webp"
}
```

| 項目 | 内容 |
|---|---|
| `id` | カードID。イラストのファイル名と一致 |
| `no` | 通し番号（1〜395）。セーブデータはこの番号で管理。新しいカードは末尾に追加する |
| `pack` | 収録パック名 |
| `name` | カード名。書き換えるとゲーム内の表示に反映されます |
| `rarity` | N / R / SR / SSR / UR |
| `element` / `motif` | 属性とモチーフ |
| `theme` | カードのテーマ（内部データ） |
| `file` | イラストファイルのパス |

## イラストの差し替え

`illust/` の同じファイル名の画像を置き換えるだけで、開封演出・結果画面・図鑑・詳細画面・共有画像のすべてに反映されます。

- サイズ: 840×1000px（縦横比 0.84）
- 形式: WebP 推奨（PNG / JPG にする場合は `cards.json` の `file` も変更）
- 文字・枠・レアリティ表示は入れない（カード枠はゲーム側で描画）
- 画像が見つからない場合は、ゲーム内の描画コードで自動生成した絵が表示されます

## イラストを描画コードから作り直す

イラストは `index.html` 内の `artTpl()` で描いたベクター画像を書き出したものです。
描画コードを変更したときは、次のコマンドで書き出し直せます。

```bash
pip install playwright pillow
python -m playwright install chromium
python tools/export_illust.py                 # 全カード + cards.json
python tools/export_illust.py SW-N001 UR015   # 指定したカードだけ
```

全件書き出しでは `cards.json` も作り直されるため、手で編集したカード名は上書きされます。

## 保存データとデータ移行

ブラウザの localStorage（キー: `prisma-collection-v1`）に以下を保存します。

- カードごとの所持枚数・初回獲得日時
- 累計開封枚数・累計10連回数
- パックごとの天井の進み具合とUR確定ガチャの残り回数
- BGM音量・SE音量・演出設定

別の端末へは、タイトル → 設定 → データ移行 で発行する「引き継ぎコード」で移せます。
ブラウザのデータを消すとセーブデータも消えるため、必要に応じて引き継ぎコードを控えてください。

## 外部依存

- フォント: Google Fonts（M PLUS Rounded 1c / Outfit）。読み込めない環境では端末のフォントで表示
- BGM・効果音は Web Audio API で合成しているため、音声ファイルはありません
